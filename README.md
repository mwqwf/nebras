# نبراس — Nebras 💡

**منصة معرفية عربية متكاملة، مفتوحة المصدر** — تطبيق جوال + لوحات تحكم (ويب وجوال) في مستودع واحد.

## الفكرة

نبراس منصة نشر معرفي عام باللغة العربية: شبكة قنوات معرفية يديرها ناشرون معتمدون، يصل محتواها (مقالات، كتب، صوتيات، مرئيات) إلى المستخدمين عبر تطبيق جوال أنيق بواجهة عربية كاملة، بينما يدير المشرفون المحتوى والمجتمع عبر لوحات تحكم مخصصة. ليست منصة دينية ولا مكتبة مفتوحة — بل قناة نشر معرفي مُدارة بجودة تحريرية.

## مكوّنات المستودع

| المجلد | المكوّن | التقنية |
|---|---|---|
| `nebras-app/` | **تطبيق نبراس للجوال** — النسخة المعتمدة | Kotlin / Jetpack Compose |
| `nebras-dashboard/` | **لوحة التحكم للجوال** — النسخة المعتمدة | Kotlin / Jetpack Compose |
| `dashboard-web/` | لوحة التحكم الأصلية (ويب + Backend) | SvelteKit / Vercel |
| `app-flutter/` | تطبيق الجوال (نسخة تاريخية) | Flutter |
| `dashboard-flutter/` | لوحة التحكم (نسخة تاريخية) | Flutter |
| `website/` | الموقع التعريفي | Next.js |

## أبرز الميزات

**التطبيق:** تصفح أقسام وقنوات معرفية، قارئ مقالات وكتب، مشغّل صوتيات ومرئيات، بحث عربي محسّن، متابعة أقسام، إشعارات ذكية data-only، روابط عميقة، «اكتشف اليوم»، مشاركة أصلية، وضع داكن.

**لوحة التحكم:** إدارة محتوى كاملة (نشر/تعديل/نقل/حذف تعاقبي)، رفع سريع للوسائط، دردشة إدارة بنمط واتساب (تفاعلات، حضور، قراءة ✓✓، صلاحيات مالك)، إشراف مجتمع، تحليلات ولوحة شرف، جدولة نشر، تنبيهات.

## ⚠️ حالة المشروع

هذا المستودع **مفصول تماماً عن أي قاعدة بيانات تشغيلية** — مشروع Firebase الأصلي حُذف نهائياً، ولا يحتوي الكود على أي مفاتيح أو أسرار أو ملفات `google-services.json` حقيقية. المشروع منشور مفتوح المصدر للاستفادة منه كمرجع معماري كامل لمنصة محتوى عربية.

## التشغيل

كل مكوّن مستقل ببيئته:

1. **أنشئ مشروع Firebase خاصاً بك** (Firestore + Storage + Auth + FCM).
2. **Kotlin (التطبيق واللوحة):** ضع `google-services.json` الخاص بك في `app/`، ثم افتح المجلد في Android Studio وابنِ مباشرة.
3. **لوحة الويب (SvelteKit):** `npm install` ثم اضبط متغيرات البيئة (مفاتيح Firebase Admin) في `.env` وانشر على Vercel.
4. **نسختا Flutter:** مرجع تاريخي؛ تحتاجان Flutter SDK و`google-services.json`.
5. **الموقع:** `npm install && npm run dev` داخل `website/`.
